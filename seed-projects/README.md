# Eden Seed Projects

Seed Projects are small, measurable interventions that allow Operation Eden to begin learning before a permanent physical Node exists.

## Initial Tri-Seed Program

### Ecological Seed

Select one measurable local restoration site and establish baseline conditions before intervention.

Possible targets:

- degraded urban plot
- riparian strip
- soil-restoration site
- pollinator corridor
- water-quality restoration site

### Agricultural Seed

Establish a regenerative food-production experiment with explicit inputs, outputs, soil measurements, water use, biological observations, and failure documentation.

### Technological Seed

Build and validate **EETU-01**, the Eden Environmental Telemetry Unit, to provide locally sovereign environmental baseline and intervention data.

See `../specs/OETS-001/`.

## Required Lifecycle

`OBSERVE → DESIGN → PROTOTYPE → MEASURE → DOCUMENT → SHARE → SEED NEXT NODE`

Every Seed Project should produce evidence and a replication artifact, not merely a narrative update.
