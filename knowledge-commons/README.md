# Operation Eden Knowledge Commons

The Knowledge Commons is the shared memory and replication layer of Operation Eden.

Its purpose is simple:

**What one Node learns should be able to strengthen the next.**

## What Belongs Here

- successful methods
- failed experiments
- ecological baseline protocols
- agricultural trials
- governance experiments
- technical specifications
- field measurements
- repair notes
- cost breakdowns
- curricula
- open datasets intentionally released for reuse
- replication guides

## Documentation Rule

Every project should eventually answer:

> Could another community reproduce this from our documentation?

If the answer is no, the documentation is not finished.

## Data Sovereignty

Open knowledge does not mean forced publication of all data.

Raw Node telemetry, sensitive ecological information, personal data, community records, and location-sensitive datasets remain governed by local consent and applicable stewardship rules.

Publication to the Commons is selective and intentional.

## Failure Policy

Failures are first-class knowledge artifacts.

When an experiment fails:

1. stop unnecessary harm;
2. record what happened;
3. identify assumptions;
4. preserve relevant evidence;
5. publish lessons where safe;
6. redesign and test again.

A documented failure can become shared intelligence for the entire network.
